# NairaBooks 🇳🇬

**Privacy-First AI Accounting for Nigerians.**

A free, browser-based accounting tool that helps you track cashflow and manage taxes in real-time. All data stays on your device—privacy by design.

## ✨ Key Features

- **Client-Side Only:** No backend, your finances never leave your browser.
- **AI-Powered:** Smart transaction categorization (simulated in POC).
- **VAT Tracking:** Automatic Input/Output VAT calculations.
- **Premium UI:** Analytics that are actually beautiful to look at.

## 🛠️ Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Runtime:** Bun

## 🚀 Quick Start

```bash
# Install dependencies
bun install

# Run development server
bun dev
```

Open [http://localhost:3000](http://localhost:3000).
